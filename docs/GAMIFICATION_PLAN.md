# 游戏化迭代方案

> 核心理念: 不是"学中国文化"，而是"玩转中国文化"
> 目标用户: 欧美用户，通过游戏体验自然吸收文化

---

## 一、核心定位转变

### 从"学习App"到"游戏App"

| 维度 | 学习App | 游戏App |
|------|---------|---------|
| 用户心态 | "我要学习" | "我想玩" |
| 内容呈现 | 知识点罗列 | 探索发现 |
| 进度感 | 完成课程 | 解锁成就 |
| 动力来源 | 自律驱动 | 好奇心+奖励 |
| 社交元素 | 学习打卡 | 竞技+炫耀 |

### 核心玩法循环

```
探索 → 发现 → 收集 → 成就 → 分享 → 探索
  ↓
答题挑战 → 获得奖励 → 解锁新内容
```

## 二、游戏化功能模块

### 2.1 探索系统 (Exploration)

#### 中国地图探索
**玩法**: 点击地图上的省份，解锁该地区的内容

```
用户点击四川 →
  动画: 水墨晕染展开 →
  发现: 熊猫、火锅、三星堆 →
  收集: 添加到图鉴 →
  奖励: XP + 解锁成就
```

**文件**: `src/screens/MapExplorationScreen.js` (新建)

```javascript
// 交互式地图
// - 点击省份触发水墨动画
// - 显示该省份的"发现物"
// - 收集进度可视化
// - 隐藏彩蛋（随机触发特殊事件）
```

#### 朝代时间轴探索
**玩法**: 滑动时间轴，穿越不同朝代

```
用户滑动到唐朝 →
  动画: 卷轴展开 →
  发现: 李白、杜甫、长安城 →
  小游戏: "唐朝诗词接龙" →
  奖励: 解锁唐朝主题头像框
```

#### 随机事件系统
**玩法**: 探索时随机触发特殊事件


```
收集方式:
- 探索发现 (主要)
- 答题奖励
- 每日签到
```

### 2.3 答题挑战 (Quiz Challenge)

#### 无限模式
**玩法**: 连续答题，答错结束，追求最高分

```
连续答对:
5题  → 连击奖励 +10 XP
10题 → 连击奖励 +30 XP + 稀有收藏品
20题 → 连击奖励 +100 XP + 史诗收藏品
50题 → 传说成就解锁
```

#### 对战模式 (本地)
**玩法**: 两人轮流答题，比拼分数

```
玩家A答题 → 答对得分 → 轮到玩家B
              ↓
         答错扣分 → 换人
              ↓
         10轮后比较总分
```

#### 每日挑战
**玩法**: 每天一组固定题目，全球排名

```
每日挑战:
- 10道题，限时作答
- 计算正确率和用时
- 生成本地排名
- 分享挑战结果
```

#### 主题挑战
**玩法**: 选择特定主题答题

```
主题:
- "唐朝大挑战" - 全部唐朝相关题目
- "美食达人" - 全部美食题目
- "地理专家" - 全部地理题目
- "节日问答" - 全部节日题目
```

### 2.6 每日系统 (Daily System)

#### 每日签到
```
签到奖励:
Day 1: 10 XP
Day 2: 20 XP
Day 3: 普通收藏品
Day 4: 40 XP
Day 5: 稀有收藏品
Day 6: 60 XP
Day 7: 史诗收藏品 + 专属头像框

连续签到加成:
7天: +10% XP
14天: +20% XP
30天: +50% XP + 传说收藏品
```

#### 每日任务
```
任务示例:
- "探索3个新省份" → 20 XP
- "答对5道题" → 15 XP
- "收集1个新收藏品" → 25 XP
- "分享1次" → 10 XP

完成全部任务 → 额外奖励宝箱
```

#### 每日幸运
```
每日一次免费抽奖:
- 普通奖品: XP、收藏品碎片
- 稀有奖品: 完整收藏品、头像框
- 传说奖品: 限定收藏品
```

## 八、风险与应对

### 风险
1. **内容过多**: 收集内容需要大量设计和数据
2. **平衡性**: 稀有度和奖励需要精心平衡
3. **上瘾性**: 需要控制游戏化程度，避免过度

### 应对
1. 分阶段上线，先核心后扩展
2. 数据埋点分析，持续优化平衡
3. 设置每日上限，保护用户健康
