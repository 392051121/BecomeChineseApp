## 二、详细对比

### 2.1 探索系统

#### 现状
```
✅ 已有:
- HomeScreen: 快捷入口 (History, Food, Places, People)
- TravelScreen: 城市列表 (卡片形式)
- FoodScreen: 美食列表 (网格卡片)
- HistoryScreen: 朝代列表 + 人物区块
- ChinaConnectionMap: 静态地图展示

❌ 缺失:
- 无交互式地图探索
- 无随机事件
- 无探索奖励
- 无发现动画
```

#### 游戏化方案
```
新增:
- 交互式地图: 点击省份触发水墨动画，发现内容
- 随机事件: 探索时触发宝藏/神秘人/传说
- 探索奖励: XP + 收藏品 + 成就
- 时间轴探索: 滑动朝代时间轴
```

#### 改造点
| 现有组件 | 改造方式 |
|----------|----------|
| `ChinaConnectionMap` | 添加点击交互，触发探索动画 |
| `TravelScreen` | 改为地图探索入口 |
| `HistoryScreen` | 添加时间轴交互 |

---

### 2.2 收集系统

#### 现状
```
✅ 已有:
- CollectionScreen: 收藏列表 (Cities/Dishes/Dynasties/People)
- 收藏功能: toggleCollectionItem
- MilestoneCard: 里程碑进度 (5/15/30/50)
- 收藏数量统计

❌ 缺失:
- 无图鉴概念
- 无稀有度
- 无收集动画
- 无收集奖励
- 无完成度展示
```

#### 游戏化方案
```
新增:
- 图鉴系统: 宝可梦式收集展示
- 稀有度: 普通/稀有/史诗/传说
- 收集动画: 卡片翻转 + 金光 + 飞入图鉴
- 收集奖励: XP + 成就 + 头像框
- 完成度: 每个分类的完成百分比
```

#### 改造点
| 现有组件 | 改造方式 |
|----------|----------|
| `CollectionScreen` | 改为图鉴展示，添加稀有度标签 |
| `MilestoneCard` | 添加奖励预览和解锁动画 |
| 数据文件 | 添加 `rarity` 字段 |

### 2.3 答题系统

#### 现状
```
✅ 已有:

```

```
- 连击奖励: 5/10/20/50连击额外奖励
- 主题挑战: 唐朝/美食/地理专题
- 对战模式: 两人轮流答题
- 答题动画: 正确/错误反馈动画
```

#### 改造点
| 现有组件 | 改造方式 |
|----------|----------|
| `CalendarScreen` | 添加"无限模式"入口 |
| 新建 `QuizScreen` | 无限模式答题界面 |

## 五、优先级建议

### 高优先级 (核心游戏化)
1. **收集系统改造** - 图鉴 + 稀有度 + 动画
2. **答题无限模式** - 连击 + 奖励
3. **成就解锁动画** - 印章 + 光芒

### 中优先级 (增强体验)
4. **每日签到** - 签到奖励
5. **地图探索交互** - 点击发现
6. **好友码 + 排行榜** - 社交竞争

### 低优先级 (锦上添花)
7. **每日任务** - 任务系统
8. **幸运抽奖** - 抽奖系统
