## 图片获取建议

### 推荐图片来源

1. **Unsplash** (免费，高质量)
   - https://unsplash.com
   - 搜索: "Chinese food", "Beijing", "Shanghai" 等

2. **Pexels** (免费，高质量)
   - https://pexels.com
   - 搜索: "Chinese cuisine", "China cityscape"

3. **Wikimedia Commons** (公共领域)
   - https://commons.wikimedia.org
   - 搜索具体菜名或城市名

4. **Pixabay** (免费)
   - https://pixabay.com

### 图片规格要求

- **格式**: JPG 或 PNG
- **尺寸**: 
  - 城市图片: 1600x1000 像素 (用于卡片展示)
  - 菜谱图片: 800x600 像素
- **内容要求**:
  - 真实的中国城市/食物照片
  - 避免日本、韩国风格的图片
  - 避免西式摆盘

### 文件命名

- 城市图片: `{city-id}.jpg` (如 `beijing.jpg`)
- 菜谱图片: `{recipe-id}.jpg` (如 `kung-pao-chicken.jpg`)

### 存放位置

- 城市图片: `assets/cities/`
- 菜谱图片: `assets/recipes/`
